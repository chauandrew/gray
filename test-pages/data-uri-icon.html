Small data: URI icon inside a large container

Pattern: a 320×44 search bar whose background is a small inline SVG magnifying-glass icon encoded as a data: URI. The icon itself is tiny, but the container is large — the container's size says nothing about the icon's real size.

Expected: the search bar renders completely normally — gray pill background, magnifying glass icon, "Search mail" text all visible. data: URIs make no network request, so there's nothing to block in the first place.

Bug if: the whole 320×44 search bar gets covered by a solid color box.

Real-world source: Gmail's search bar.
