Class toggled onto an already-mounted node

Pattern: a container exists in the DOM from page load with no background-image at all. ~1s later, JS adds a class that makes a stylesheet rule apply a real background-image — no node is added or removed, only a class attribute changes.

Expected: nothing happens for the first second (there's no image yet — nothing to block or box). After the class is added, the card should get boxed in your chosen color within about 200ms.

Bug if: the card never gets boxed after the class is added — it would mean the mutation observer isn't watching attribute changes, only added/removed nodes.

Real-world source: LinkedIn promo cards.
